# Pose library (copy these pose lists into action-sheet prompts)

Name sheets `<character>_<verb>`. Eight poses, row-major, view in brackets. Four-pose close-ups are marked 2×2.

| Sheet | Poses |
| --- | --- |
| `_walk_side` | contact R (profile), down, passing, up, contact L, down, passing, up |
| `_walk_toward` | 8 walk poses all (front), alternating feet |
| `_walk_away` | 8 walk poses all (back), alternating feet |
| `_run` | 8 run poses (profile), one with both feet off the ground |
| `_turn_around` | front, front ¾, profile, back ¾, back, back ¾ other side, profile other side, front ¾ |
| `_look_up` | stand (front ¾), head tilts up 1, 2, 3, trunk/arm points up, hold, blink, smile up |
| `_jump_onto` | crouch (¾), deeper crouch, push off, airborne rising (profile), peak tuck, falling, impact squash, stand |
| `_hop_down` | stand at edge, lean, step off, airborne, landing squash, recover, look back, stand |
| `_climb` | reach up, grip, pull 1, knee up, pull 2, top reach, crawl over, stand on top |
| `_sit_gaze` | stand, bend, half sit, sit, settle, look up, blink, smile |
| `_crouch` | stand, bend, crouch, crouch hold, look, peek, rise, stand |
| `_shiver` | stand, shiver L, shiver R, hug self, shiver L, shiver R, shake head, stand |
| `_reach_back` / `_pick_up` | stand, reach, grasp, lift 1, lift 2, hold up, look at it, hold at chest |
| `_open_umbrella` (with prop ref) | closed held, lift, push 1, half open, open, raise, twirl, hold |
| `_carry` | 8 walk poses holding the prop in the same hand (profile) |
| `_give_receive` | hold, extend, offer, release, other takes, step back, wave, smile |

| `_spin` | front, ¾, profile, back, profile other side, ¾, front dizzy, steady |
| `_wave` | stand, arm up, wave L, wave R, wave L, wave R, arm down, smile |
| `_droop` (2×2) | neutral, ears drop, head down, sigh |
| `_close_wonder` (2×2) | neutral, eyes wide, mouth open, gasp smile |
| `_close_joy` (2×2) | smile, laugh eyes closed, bounce, grin |

| `_sleep` | yawn, stretch, lie down, curl, eyes close, breathe in, breathe out, still |
